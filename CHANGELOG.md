# Press R to Remove v1.5

🎉 Initial Public Release

A Windhawk mod that lets you quickly remove Start Menu recommendations and Taskbar Jump List items using a configurable hotkey.

## Highlights

- Configurable hotkeys (R, Delete, Backspace, F8-F10)
- Supports Start Menu recommendations
- Supports Taskbar Jump Lists
- English and Traditional Chinese support
- Tested on Windows 11 24H2
